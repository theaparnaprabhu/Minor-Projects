# PCB Design Practice Projects (KiCad)

A curated collection of PCB design and schematic practice projects completed while learning **KiCad** after my **first year of Electronics and Communication Engineering**. I learned PCB design during my **summer vacation before the start of second year**, while doing an internship, and used this period to practice schematic capture, footprint assignment, PCB routing, grounding, connector placement, and design-rule verification through multiple hands-on projects.

The focus of this collection is practical PCB workflow rather than theoretical circuit analysis.

## Tools Used

* KiCad 9
* 2-layer PCB design
* Schematic editor
* PCB editor
* Copper pours and ground planes
* ERC / DRC checks

---

## Featured Projects

### TB6612FNG Breakout

Compact breakout board for the TB6612FNG dual H-bridge motor driver.

**Highlights**

* Custom footprint usage
* Decoupling capacitor placement
* Motor power and logic routing
* Compact board layout

---

### L298 Motor Driver

PCB for an L298-based dual motor driver module.

**Highlights**

* High-current routing
* Connector placement
* Mounting-hole planning
* Power distribution layout

---

### Variable Power Supply

Adjustable regulated power supply PCB.

**Highlights**

* Regulator section layout
* Potentiometer interface
* Input/output filtering
* Power trace sizing

---

### Audio Amplifier

Analog amplifier PCB for low-power audio applications.

**Highlights**

* Analog signal routing
* Component grouping
* Grounding considerations
* Noise-aware layout

---

### Seven Segment Module

Driver/interface PCB for a seven-segment display module.

**Highlights**

* Symmetrical component placement
* Clean routing
* Readable silkscreen
* Compact digital layout

---

### Battery Charger

Battery charging circuit PCB practice project.

**Highlights**

* Charging path routing
* Power connector layout
* Protection component placement
* Thermal spacing awareness
